## Setup Instructions

### Step 1: Configure WhatsApp Business API
1. Navigate to **Automations & Reminders** page
2. Click **"WhatsApp API Config"** button
3. Go to [Meta Business Suite](https://business.facebook.com/wa/manage/home/)
4. Create or select your WhatsApp Business Account
5. Navigate to **API Setup** and copy:
   - WhatsApp Business API Key (Permanent Access Token)
   - Phone Number ID
   - Business Account ID
6. Paste credentials in the configuration modal
7. (Optional) Configure Webhook URL for delivery status
8. Click **"Test Connection"** to verify
9. Save configuration when verified ✅

### Step 2: Create Automation
1. Click **"Create Automation"** button
2. **Settings Tab**:
   - Select automation type (Low Stock, Payment, Report, Order)
   - Enter automation name and description
   - Configure WhatsApp phone number (with country code)
   - Set frequency (Immediate, Daily, Weekly, Monthly)
   - Configure type-specific settings (threshold, days, time, etc.)
3. **Message Template Tab**:
   - View available variables for the selected type
   - Customize message template
   - Click variables to insert them at cursor position
   - Use live preview to see how message will look
   - Reset to default if needed
4. Enable automation and save

### Step 3: Test & Monitor
1. Use **"Test Message"** button to send a sample
2. Monitor automation cards for:
   - Active/Inactive status
   - Last triggered time
   - Total triggered count
3. Edit messages anytime from the automation card

## Technical Details

### Data Structure
```javascript
// Automation Object
{
  id: 'AUTO-001',
  type: 'low_stock',
  name: 'Low Stock Alert',
  description: 'Get notified when stock goes below threshold',
  enabled: true,
  channel: 'whatsapp',
  phone: '+91 98765 43210',
  frequency: 'immediate',
  threshold: 10,
  messageTemplate: 'low_stock_alert',
  customMessage: '🚨 *Low Stock Alert*\n\nProduct: {{product_name}}...',
  lastTriggered: Date,
  triggeredCount: 12
}

// API Config Object
{
  apiKey: 'YOUR_PERMANENT_ACCESS_TOKEN',
  phoneNumberId: '123456789012345',
  businessAccountId: '987654321098765',
  webhookUrl: 'https://your-domain.com/webhook/whatsapp',
  isConfigured: true,
  verificationStatus: 'verified' // pending, verified, failed
}
```

### Message Template Variables
Each automation type has predefined variables that get replaced with actual data:
- Variables use double curly braces: `{{variable_name}}`
- Sample data is shown in preview mode
- Variables are validated before sending

### Permissions
- **View Automations**: `settings.view`
- **Create/Edit/Delete**: `settings.edit`
- Buttons are hidden if user lacks permissions
