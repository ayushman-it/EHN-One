# EHN One - Inventory Management System

Complete full-stack inventory management system built with React and Node.js.

## Features

- 📊 Dashboard with real-time statistics
- 📦 Products management with categories
- 🏢 Supplier and warehouse management
- 📝 Invoice generation
- 📱 WhatsApp automation and reminders
- 👥 User management with role-based access
- 🔔 Real-time notifications
- 📈 Transaction history and analytics

## Quick Start

### Backend Setup
```bash
cd backend
npm install
npm run seed
npm start
```

### Frontend Setup
```bash
cd frontend
npm install
npm start
```
