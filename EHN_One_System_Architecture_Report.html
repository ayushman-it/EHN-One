4. Security & Data Protection Policies
  • Identity Protection: Full Name, Email, Role, and Department are strictly read-only for non-admin accounts. Only Administrators can alter user identities.
  • Self-Service Controls: All authenticated users can upload their own profile avatar and update password securely.
  • Immutable Audit Logging: Every sensitive action (logins, role updates, invoice cancellations, stock edits) is recorded with IP address, user ID, timestamp, and severity level.
